Blip
English · 日本語

マウスカーソルを見つける。

ディスプレイを増やすほど、カーソルはどこかへ行きます。ホットキーを押せば、いまある場所が光ります。

無料。オープンソース。エフェクトは 4 種類。

GitHub からダウンロード
Homebrew を使う場合
brew install --cask dominion525/tap/blip-cursor

MIT ライセンスのオープンソース · macOS 13 以降 · Apple Silicon · 署名・公証済み

光らせ方は 4 種類

設定ウインドウで選びます。エフェクトは 1.2 秒で消えます。

  • 集中線

    マンガの集中線をカーソルに向け、3 コマで揺らします。

  • スポットライト

    画面を暗転させ、カーソルの周りにリング付きの穴を開けます。

  • ズーム

    画面サイズの穴をカーソルに向かって縮めます。

  • フラッシュ

    リングを点滅させ、カーソルから波紋を広げます。

録画は Wikipedia 日本語版「バーフバリ 王の凱旋」（CC BY-SA 4.0）、記事内の写真は Bollywood Hungama（CC BY 3.0）。

出し方は 2 通り

どちらも設定ウインドウで変更でき、切ることもできます。

  • ホットキー

    既定は ⌥ ⌘ Z。フィールドを押して、使いたいキーを入力します。

  • 修飾キーの 2 回押し

    既定は左 Control。左右の Control、Shift、Option、Command から選べます。

表示中はカーソルを追いかけ、下にあるアプリはそのままクリックできます。ディスプレイが複数ある場合、エフェクトはカーソルのある画面にだけ出て、他の画面は暗転します。

更新

Blip は新しい版を自分で見に行き、鍵で検証してから入れ替えます。Homebrew で入れている場合は brew upgrade でも上がります。
