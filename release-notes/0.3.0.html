Blip is a menu bar utility that finds your mouse cursor. Press a hotkey or double-tap a modifier key, and the cursor position lights up.

What changed since 0.2.1

  • The effect lasts as long as you want it to. It used to end after a fixed 1.2 seconds, which is a guess that holds on a laptop screen and not on a projector. Settings now offers 0.1 to 5.0 seconds in tenths, and an option to keep it up until you use the pointer. That one ends when the cursor is moved and then set down, or on a click of any mouse button
  • The About panel links out. The app's site and its author are now clickable

Install

brew install --cask dominion525/tap/blip-cursor

Or download Blip-0.3.0.zip or Blip-0.3.0.dmg and move Blip.app into Applications. The app is signed with a Developer ID certificate and notarized, so it opens without a Gatekeeper warning.

Replacing an installed copy in Applications keeps its settings and the Input Monitoring permission.

Requires macOS 13 or later on Apple Silicon. Intel Macs are not supported.

Blip はマウスカーソルを見つけるためのメニューバーユーティリティです。ホットキーを押すか修飾キーを 2 回押すと、カーソルの位置が光ります。

0.2.1 からの変更

  • エフェクトの表示時間を選べるようになりました。 これまでは 1.2 秒で固定でした。手元の画面では妥当でも、プロジェクターでは足りないことがあります。設定から 0.1 〜 5.0 秒を 0.1 刻みで指定できるようになり、加えて「操作するまで消さない」を選べます。この場合はカーソルを動かして止めたとき、またはマウスのボタンを押したときに消えます
  • About パネルからサイトへ飛べるようになりました。 アプリのサイトと作者のサイトがクリックできます

インストール

brew install --cask dominion525/tap/blip-cursor

または Blip-0.3.0.zip か Blip-0.3.0.dmg をダウンロードし、Blip.app を Applications に移します。アプリは Developer ID 証明書で署名し公証済みなので、Gatekeeper の警告なしに開きます。

Applications に入っている版を置き換えても、設定と入力監視の許可は保持されます。

Apple Silicon の macOS 13 以降が必要です。Intel Mac には対応しません。
