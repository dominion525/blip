Blip is a menu bar utility that finds your mouse cursor. Press a hotkey or double-tap a modifier key, and the cursor position lights up.

What changed since 0.1.1

  • Blip updates itself. The status bar menu has a Check for Updates item. When a newer version is out, Blip offers it, verifies the download against its signing key, and swaps itself for it
  • Install with Homebrew. brew install --cask dominion525/tap/dominion525-blip
  • A disk image to drag from. Releases now carry a .dmg next to the .zip, with the app and a link to Applications side by side

Install

Download Blip-0.2.0.zip or Blip-0.2.0.dmg, and move Blip.app into Applications. The app is signed with a Developer ID certificate and notarized, so it opens without a Gatekeeper warning.

Replacing an installed 0.1.x in Applications keeps its settings and the Input Monitoring permission.

Requires macOS 13 or later on Apple Silicon. Intel Macs are not supported.

Blip はマウスカーソルを見つけるためのメニューバーユーティリティです。ホットキーを押すか修飾キーを 2 回押すと、カーソルの位置が光ります。

0.1.1 からの変更

  • Blip が自分で更新します。 ステータスバーのメニューに「更新を確認」が入りました。新しい版が出ていると知らせ、ダウンロードしたものを署名鍵で検証してから入れ替えます
  • Homebrew で入れられます。 brew install --cask dominion525/tap/dominion525-blip
  • ドラッグして入れられるディスクイメージ。 リリースに .zip と並んで .dmg が付きます。アプリと Applications へのリンクが並んでいます

インストール

Blip-0.2.0.zip か Blip-0.2.0.dmg をダウンロードし、Blip.app を Applications に移します。アプリは Developer ID 証明書で署名し公証済みなので、Gatekeeper の警告なしに開きます。

Applications に入っている 0.1.x を置き換えても、設定と入力監視の許可は保持されます。

Apple Silicon の macOS 13 以降が必要です。Intel Mac には対応しません。
