Blip is a menu bar utility that finds your mouse cursor. Press a hotkey or double-tap a modifier key, and the cursor position lights up.

What changed since 0.2.0

  • Updates actually arrive. 0.2.0 announced itself with a version the updater could not compare against the installed one, so it would never have offered anything. Fixed, and verified end to end
  • The menu reads by what each item does. Check for Updates now sits with Restart, since both put a different copy of the app on screen, rather than with Settings and About

Install

brew install --cask dominion525/tap/dominion525-blip

Or download Blip-0.2.1.zip or Blip-0.2.1.dmg and move Blip.app into Applications. The app is signed with a Developer ID certificate and notarized, so it opens without a Gatekeeper warning.

Replacing an installed copy in Applications keeps its settings and the Input Monitoring permission.

Requires macOS 13 or later on Apple Silicon. Intel Macs are not supported.

Running 0.2.0? Blip will not offer this update to you, for the reason above. Download it here, or run brew upgrade.

Blip はマウスカーソルを見つけるためのメニューバーユーティリティです。ホットキーを押すか修飾キーを 2 回押すと、カーソルの位置が光ります。

0.2.0 からの変更

  • 更新が実際に届くようになりました。 0.2.0 は、入っている版と比べられない形の版番号を名乗っていたため、更新を提示することがありませんでした。修正し、端から端まで動作を確認しました
  • メニューを役割で組み直しました。 「更新を確認」を「再起動」の隣に移しました。どちらもアプリを別の版に入れ替えて画面に出す操作で、設定や About とは性質が違うためです

インストール

brew install --cask dominion525/tap/dominion525-blip

または Blip-0.2.1.zip か Blip-0.2.1.dmg をダウンロードし、Blip.app を Applications に移します。アプリは Developer ID 証明書で署名し公証済みなので、Gatekeeper の警告なしに開きます。

Applications に入っている版を置き換えても、設定と入力監視の許可は保持されます。

Apple Silicon の macOS 13 以降が必要です。Intel Mac には対応しません。

0.2.0 をお使いの場合、上記の理由でこの更新は提示されません。ここからダウンロードするか、brew upgrade を実行してください。
